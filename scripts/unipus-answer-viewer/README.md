# U校园答案显示器

用于 U 校园练习页面。侧边面板读取并展示答案，支持部分题型填充和题目切换后的刷新。

## 功能

- 在 U校园相关域名中识别练习页面。
- 读取并解析页面所需的作答数据。
- 在浮动面板中展示答案和处理状态。
- 支持选择题、判断题、填空题、匹配题、下拉题、排序题、单词听写、改错题的填充，以及题目切换后的刷新。
- 改错题按答案记录逐个单词修改，句子已有错误修改时先撤销再重填。
- 提供日志开关，便于排查页面更新后的问题。

## 适用范围

- 网站：U校园相关域名。
- 页面：`sso.unipus.cn`、`uai.unipus.cn`、`ucontent.unipus.cn`。
- 浏览器：支持 Tampermonkey 的现代浏览器。
- 脚本管理器：Tampermonkey。

## 使用方法

安装后进入 U校园练习页面，使用页面上的浮动按钮读取或填充当前题目。

## 已知限制

- 依赖 U校园当前前端接口和页面结构。
- 不同课程、题型和页面版本的显示效果可能不完全一致。
- 只测试了新视野课程，理解当代中国课程明确不支持，答案仅在提交作答后返回。
- 只处理文字作答的客观题。口语题（录音、复述、跟读）和需要拖动滑块的自评题不填充，因为答案要靠现场录音或滑动手感产生。
- 改错题每句只允许一处修改，脚本会先撤销该句上多余的或内容不对的既有修改，再写入答案。
- 单词听写靠派发键盘事件逐字母写入，若页面改用以输入框渲染字母，写法需要跟着改。
- 填空、匹配类题目只按页面输入框顺序分配答案，答案条数与输入框数量不一致时可能错位。
