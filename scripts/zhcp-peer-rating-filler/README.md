# 西农综测班级互评填分助手

用于综合测评的班级互评打分弹窗。按设定的档位为整张表批量生成分数，分数在档位附近随机浮动，填好后由你自己核对并点保存。

## 功能

- 识别当前班级互评弹窗，统计单元格数量、同学人数和已填写数量。
- 读取每个单元格自带的分值上下限，档位按各自区间换算，同一档位可用于 0-4、0-10、3-6 等不同区间的指标。
- 档位可用滑块或数字输入调节，并可设置浮动幅度，避免所有人分数完全相同。
- 支持按区间比例和按分值两种档位方式，按分值时超出该项上下限的部分会被裁剪。
- 可限制满分数量，超出的满分会下调一个最小步长。
- 可跳过已填写的单元格，避免覆盖手工输入。
- 填写前弹窗列出待填数量、分值范围、档位和实际生成区间，确认后才写入。
- 列出页面上的全部班级互评项及完成状态，点击可直接打开对应弹窗。
- 提供清空按钮，只清空页面输入框。
- 面板可拖动、可收起，档位设置和面板位置保存在浏览器本地。

## 适用范围

- 网站：西北农林科技大学学生服务综合测评应用。
- 页面：综测打分页面中的班级互评打分弹窗。
- 浏览器：支持 Tampermonkey 的现代浏览器。
- 脚本管理器：Tampermonkey。

## 使用方法

安装后打开综测打分页面，在面板中点击要填写的班级互评项，调好档位后点击一键填写，确认弹窗后核对分数，再点击页面上的保存。

## 已知限制

- 脚本不会点击保存或提交，也不会替你确认系统自带的保存弹窗。
- 只支持班级互评的数字输入表格。宿舍互评是选项式的，面板会提示不支持。
- 依赖页面现有结构，包括互评表格容器、输入框上的分值上下限属性和互评入口的按钮属性。学校调整页面后可能失效。
- 系统要求整张表填满才能保存，跳过已填写时请确认没有遗漏。
- 按分值档位遇到多种分值范围的弹窗时会被各自上下限裁剪，此时更适合用按区间比例。
- 分数由你自己决定，脚本只负责写入，不对评价内容做任何判断。
